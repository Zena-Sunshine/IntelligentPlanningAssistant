# Third-party evaluation data

`datasets/crosswoz_external_holdout.jsonl` contains a deterministic subset of
user utterances from CrossWOZ:

- Project: CrossWOZ
- Authors: Qi Zhu, Kaili Huang, Zheng Zhang, Xiaoyan Zhu, Minlie Huang
- Upstream: https://github.com/thu-coai/CrossWOZ
- Pinned commit: `df82c9fdff91b9b130f2d6b89110d3870ba6260e`
- Upstream split: `test`
- Repository license: Apache License 2.0
- Paper: Zhu et al., “CrossWOZ: A Large-Scale Chinese Cross-Domain Task-Oriented Dialogue Dataset,” TACL 2020

The utterance text is unchanged. VoyageIQ adds a documented mapping from the
upstream dialogue-act domains to a limited product taxonomy. Review the
upstream license and attribution requirements before redistributing a release
artifact containing the dataset.
